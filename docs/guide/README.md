# AI로 대시보드 만들기 — 알아야 할 8가지 (가이드)

AI에게 대시보드를 시킬 때 **처음부터 다시 만들지 않으려면** 알아야 할 것을 A4 21쪽으로 정리한 가이드입니다. 코드를 가르치는 자료가 아니라 **AI와 일하는 방법** 자료입니다. 쪽마다 AI에 붙여넣는 프롬프트가 있고, ❌/✅ 비교와 "성공하면"으로 확인합니다.

| 위치 | 내용 |
|---|---|
| `index.html` | 가이드 본문 (한 파일, 인터넷 불필요, 브라우저로 열기) |
| `AI_대시보드_가이드.pdf` | 같은 내용의 PDF (A4, 21쪽) |
| `src/` | 원본 조각(`a`~`e`)과 조립 스크립트 `build.py` |
| `img/` | 화면 캡처 (가상 샘플 데이터, 업체명은 일반 라벨) |

## 구성 (21쪽)

| 쪽 | 내용 |
|---|---|
| 1 | 표지·차례 |
| 2 | **지도 한 장** — 입력·과정·출력 세 칸, 일이 커질수록 바깥으로(묻기 → 만들기 → 일 시키기 → 맡기기), 원칙 3가지(MVP부터 · 도구는 끝까지 · 되돌릴 수 없는 일은 내가) |

| 7–8 | STEP 2 목업 — ① 열 이름 + 가상 데이터 ② **스케치 한 장으로 원하는 배치 전하기** |
| 9–10 | STEP 3 **보기 좋게 만들기** — 디자인 기준 5가지, 나쁜/좋은 화면 비교, 디자인 요청 프롬프트 7가지, 3초 테스트 |

## 보는 법

- 프롬프트 상자 오른쪽 위 **복사** 버튼 → 그대로 AI에 붙여넣기. `<…>` 로 표시된 곳만 내 내용으로 바꿉니다.
- 그림을 누르면 확대, `Esc`로 닫기. 차례를 누르면 해당 쪽으로 이동.
- 인쇄: 브라우저 인쇄 → A4 (쪽마다 1장). 휴대폰에서는 한 줄 레이아웃으로 바뀝니다.

## 고치는 법

1. `src/*.html`에서 해당 쪽을 고칩니다. 쪽은 `<section class="sheet" id="pN" data-sec="…">` 한 덩어리이고, A4 한 장에 들어가야 합니다. 쪽을 더하거나 빼면 id(`p1`…)를 순서대로 다시 매기고 차례(`#p…` 링크)와 본문의 "N쪽" 표기도 맞춥니다.
2. `python src/build.py` — 한 파일(`index.html`)로 조립하고 쪽 번호·링크·이미지를 점검합니다. 쪽 번호("N / 21")와 바닥글은 자동입니다.
3. PDF는 브라우저로 `index.html`을 열어 A4로 인쇄(PDF로 저장)하면 됩니다.

## 주의
