QUICK START5분

AI에게 "대시보드 만들어줘"라고 하기 전에

그럴듯한데 내 업무와는 안 맞는 화면이 나옵니다. 고쳐 달라고 하면 다른 곳이 바뀌고, 결국 처음부터 다시 하게 됩니다.

문제는 AI가 아니라 순서입니다. 질문·기준·규칙은 사람이 정하고, 만드는 일은 AI가 하고, 맞는지는 다시 사람이 숫자로 확인합니다. 이 가이드는 그 순서를 8스텝으로 정리했습니다.

사람이 정하고 확인AI가 만듦함께 반복
복사해서 바로 시작하는 프롬프트: 내 대시보드 설계서를 AI와 한 장으로 만들기AI 대화창을 열고 첫 메시지로 붙여넣으세요. 꺾쇠(< >)로 표시된 세 곳만 내 상황으로 바꾸면 됩니다.
AI 대화창에 붙여넣기
역할: 대시보드 기획을 도와주는 담당. 코드는 아직 쓰지 않습니다.
맥락: 저는 개발 경험이 없는 업무 담당자입니다. 엑셀 데이터를 AI와 함께 대시보드로 만들려고 합니다.
입력:
- 내 업무 = <어떤 업무의 어떤 데이터를 보고 싶은지 한 줄. 예: 월별 매출·재고>
- 볼 사람 = <누가 얼마나 오래 보는지. 예: 팀장이 월요일 회의에서 1분>
- 엑셀 열 이름 = <열 이름만 나열. 값(업체명·금액 등)은 절대 적지 않습니다>
작업:
① 한 번에 질문 3개씩만 하면서, 이 대시보드가 답해야 할 질문을 3개로 좁혀 주세요
② 질문마다 KPI(숫자)와 비교 기준(전년·목표·평균 중 하나)을 제안해 주세요
③ 화면을 요약 / 분석 / 개별 중 필요한 것만 골라 화면 정의서 표로 만들어 주세요
④ 결과 숫자가 달라질 수 있는 모호한 규칙(등급 구간, 빈칸 처리, 증감 표시 등)을 "확인할 질문"으로 따로 뽑아 주세요
⑤ 당신이 한 가정은 "가정 목록" 표로 적어 주세요
제약: 실제 데이터 값을 요구하지 마세요. 코드는 쓰지 마세요. ①이 끝나면 멈추고 제 답을 기다리세요.
출력: 질문 3개 / KPI 표 / 화면 정의서 표 / 확인할 질문 목록 / 가정 목록
검증: 마지막에 "이 질문에 답하지 않는 차트는 없는가"를 스스로 점검해 한 줄로 알려 주세요.
성공하면질문 3개, KPI 표, 화면 정의서, 확인할 질문, 가정 목록이 나옵니다. 이 결과가 STEP 1~5의 재료가 됩니다.
시작하기 전에2분

프롬프트는 두 곳에서 씁니다

프롬프트 위에 '붙여넣을 곳'이 표시되어 있습니다. 같은 AI라도 하는 일이 다릅니다.

AI 대화창

질문 정리, 목업, 규칙, 지시서 초안을 만드는 곳입니다. 예: Claude. 내 폴더의 파일을 직접 고치지는 않습니다.

AI 코딩 도구

내 폴더에서 파일을 만들고 실행하며 실제 대시보드를 구현하는 곳입니다. 예: 사내 opencode, Claude Code.

이 가이드에 나오는 용어

대시보드: 핵심 숫자와 차트·표를 한 화면에 모아 보여 주는 화면입니다.

KPI: 대시보드의 핵심 숫자입니다. '평균 점수 + 전년 대비'처럼 비교 기준을 붙입니다.

목업: 가짜 데이터로 먼저 만들어 보는 화면 시안입니다.

지시서: AI 코딩 도구에게 줄 작업 설명서입니다. 규칙·단계·완료 기준이 들어갑니다.

정답값: 가상 데이터로 미리 정해 둔 기대 숫자입니다. 만든 결과가 맞는지 대조하는 기준입니다.

한눈에 보는 정보

한 줄 정의
AI로 대시보드 만들기는 사람이 정하고, AI가 만들고, 사람이 숫자로 확인하는 일입니다.
필요한 것
AI 대화창, AI 코딩 도구, 브라우저, 내 엑셀. 별도 프로그램 설치는 거의 없습니다.
필요한 지식
없음. 엑셀을 열 수 있고 "이 숫자가 맞나?"를 확인할 수 있으면 충분합니다.
비용
사내 도구를 쓰면 추가 결제가 없습니다. 외부 AI 서비스는 사내 정책을 먼저 확인하세요.
잘 맞는 경우
엑셀 결과를 읽고 보는 화면. 갱신이 일·주·월 단위이고 데이터가 수천~수만 행.
안 맞는 경우
화면에서 데이터를 입력·수정해야 하거나 실시간 갱신, 사람마다 보이는 데이터가 다른 경우 → 개발 담당자와 상의하세요.
시작 전 안전망3분

AI에게 주지 않을 것, 남겨 둘 것

일을 맡기기 전에 정해 두면 되돌릴 일이 없습니다. 특히 ①은 한 번 보내면 되돌릴 수 없습니다.

① AI에게 줄 것과 주지 않을 것

줄 것 주지 않을 것
열 이름 · 형식(숫자·날짜) · 규칙(등급 구간 등) · 가상 데이터업체명·금액·개인정보 · 사내 문서 원문 · 비밀번호·키·토큰

열 이름도 사내 용어일 수 있습니다. 외부 AI에는 '평가점수'처럼 일반화한 이름을, 실제 이름은 사내 AI 도구에만 알려 주세요.

② 원본은 복사본으로

엑셀 원본은 건드리지 않고 복사본으로 작업합니다. AI가 만든 도구가 원본을 덮어쓰지 못하게 "원본은 읽기만 한다"를 지시서에 적어 둡니다(STEP 6).

③ 저장 지점 만들기

마음에 드는 버전마다 폴더를 통째로 복사해 이름을 붙이세요(대시보드_v1, v2…). git을 쓴다면 아래 3줄로 한 번 저장합니다.

터미널에서 실행
git init
git add .
git commit -m "v1 저장"
성공하면git status를 쳤을 때 nothing to commit, working tree clean이 보입니다.

④ 사내 규칙 확인

외부 AI 서비스에 올려도 되는 정보의 범위, 저장소(사내 GitHub) 사용 규칙을 먼저 확인하세요. [사내 AI 사용 지침 링크 · 담당자]

이미 데이터를 붙여넣었다면멈추고 담당자에게 알리세요. 숨기거나 지우기 전에 알리는 편이 안전합니다.
STEP 15분

질문부터 정하기

이 단계에서는 "무엇을 보여 줄까"가 아니라 "이 화면으로 무엇을 결정할까"를 한 문장으로 적습니다.

이렇게 말고

"매출 대시보드 만들어줘"

AI가 흔한 차트를 채워 넣습니다. 내 질문에 답하는 차트인지 알 수 없습니다.

이렇게

"팀장이 월요일 회의에서 '이번 달 매출이 지난달보다 좋아졌는지, 어느 제품이 문제인지'를 1분 안에 보게 하고 싶습니다."

누가, 얼마나 오래, 무엇을 결정하는지가 들어 있습니다.

Quick Start의 프롬프트를 이미 썼다면 그 결과가 STEP 1입니다(대화는 10~20분이면 충분합니다). 질문이 이미 있다면 아래 짧은 버전을 씁니다.

AI 대화창에 붙여넣기
아래 질문에 답하는 대시보드의 KPI와 화면을 제안해 주세요.
질문: <이 화면으로 결정하려는 것 한두 가지>
볼 사람: <누가, 얼마나 오래 보는지>
각 KPI에는 비교 기준(전년·목표·평균 중 하나)을 붙이고, 질문에 답하지 않는 차트는 넣지 마세요.
표로 정리해 주세요: 질문 / KPI / 비교 기준 / 어느 화면에 놓을지
성공하면질문 2~3개, 질문마다 "숫자 + 비교 기준"인 KPI, 화면 구성이 표로 나옵니다.

용어: 비교 기준은 전년·목표·평균처럼 숫자가 좋은지 나쁜지 알려 주는 기준입니다. 비교 기준이 없는 숫자는 해석할 수 없습니다.

화면은 세 가지면 충분합니다

화면누가 · 얼마나담는 것
요약경영진·팀장 · 1분결론 3줄, 핵심 숫자 4개, 추이
분석담당자 · 10분영역·항목별 비교, 필터, 기준선
개별리뷰하는 사람 · 대상 1개한 대상의 추이, 항목별 순위, 세부 내용
첫 버전(MVP)은 질문 1~2개로질문이 3개를 넘으면 화면이 복잡해지고 시작도 못 합니다. 가장 급한 1~2개로 먼저 만들고, 되면 넓히세요. 질문에 답하지 않는 차트는 넣지 않습니다.

열 이름과 형식만 알려 주고 "값은 가상으로 만들어"라고 하기

AI 대화창에 붙여넣기
역할: 대시보드 화면 목업을 만드는 담당
맥락: 아래 화면 정의서를 눈으로 보고 싶습니다. 실제 값은 모릅니다.

- 화면 정의서 = <STEP 1 결과 표 붙여넣기>

① 핵심 숫자 1개를 가장 크게, 맨 위에

"느낌"이 아니라 "무엇을 어떻게"로 고칩니다. 구현 전에 많이 고칠수록 쌉니다.

이렇게

"카드를 6개 이하로 줄이고 핵심 숫자 1개만 2배로 키워 주세요. 나머지는 그대로."

바꿀 것과 그대로 둘 것이 분명합니다.

STEP 510분

계산 규칙을 숫자로 못 박기

AI가 "알아서 그럴듯하게" 채울 수 있는 규칙을 숫자로 고정합니다. 규칙이 모호하면 화면은 그럴듯해도 숫자가 틀립니다.

이렇게 말고

"등급은 점수에 따라 알아서 나눠 줘"

AI가 구간을 마음대로 정합니다. 화면마다 다를 수도 있습니다.

이렇게

"90점 이상 A, 80점 이상 B, 60점 이상 C, 60점 미만 D. 경계값: 90.0은 A, 89.9는 B"

경계값까지 적으면 AI가 틀릴 여지가 없습니다.
AI 대화창에 붙여넣기
아래 화면 정의서와 목업을 보고, 결과 숫자가 달라질 수 있는 모호한 규칙을 질문 목록으로 뽑아 주세요.
예: 등급 구간, 빈칸 처리, 동점 순위, 증감 표시, 평균 계산 방식, 비교 기간
제가 답하면 "규칙표"(규칙 / 정의 / 경계값 예시)로 정리해 주세요.
제가 모르는 항목은 "임시 기준"으로 표시하고, 나중에 설정만 바꿔 고칠 수 있게 따로 모아 주세요.
화면 정의서: <STEP 1 표 붙여넣기>
성공하면질문 목록이 나오고, 내가 답하면 "규칙표"와 "임시 기준" 목록이 만들어집니다.

규칙표는 이런 모양입니다

규칙정의 예경계값 예
등급 구간90 이상 A · 80 이상 B · 60 이상 C · 그 외 D90.0 → A, 89.9 → B, 60.0 → C, 59.9 → D
빈칸 처리빈칸은 0이 아니라 "없음"으로 보고 평균에서 제외[80, 빈칸, 90]의 평균 = 85
동점 순위같은 점수는 같은 순위, 다음 순위는 건너뜀90·85·85·80 → 1·2·2·4
증감 표시▲ 상승 / ▼ 하락 / – 변화 없음, 소수 1자리. 이탈률·비용은 오르면 나쁨(빨강)+0.04 → "– 0.0점"
월 정렬월은 글자가 아니라 순서 번호로 정렬2월, 10월 → 2월이 먼저
비율 식식으로 적기: 영업이익률 = 영업이익 ÷ 매출 × 100. 분모가 0이면 "–"매출 0 → "–"

용어: 경계값은 구간이 바뀌는 바로 그 숫자, 임시 기준은 나중에 바뀔 수 있는 값입니다.

임시 기준에는 "임시" 표시를 달아 두세요확정되기 전 값이 보고서에 인용되는 사고를 막습니다.

지금까지 정한 것을 한 문서로 묶습니다. AI 코딩 도구는 이 문서만 보고 일합니다.

이렇게 말고

"이 목업을 진짜 대시보드로 만들어줘"

규칙을 바꾸고 요약해 버립니다.

이렇게

목업 + 규칙표 + 가정 + 단계 + 완료 기준 + 하지 말 것을 한 문서로 묶기

AI가 헤맬 곳이 없습니다.
AI 대화창에 붙여넣기
지금까지 정한 화면 정의서·규칙표·가정 목록·목업을 모아 "구현 지시서" 초안을 써 주세요.
구성:
① 요약 ② 절대 규칙(인터넷 없이 동작, 데이터 보호, 외부 서비스 호출 금지, 원본 엑셀은 읽기만)
③ 진행 단계(환경 점검 → 화면 틀 → 화면별 구현 → 엑셀 연결 → 검증)
④ 데이터 읽기 규칙 ⑤ 계산 규칙(숫자와 경계값) ⑥ 화면 명세
⑦ 검증 체크리스트(정답값 포함) ⑧ 가정 목록 ⑨ 최종 보고 양식
모호한 곳은 질문으로 멈추지 말고 "가정"으로 적어 주세요. 단계마다 "이것이 되면 다음 단계"를 한 줄로 적어 주세요.
성공하면9개 항목의 지시서 초안이 나옵니다. 사람이 읽고 틀린 가정을 고칩니다.

지시서에 들어가는 9가지

① 요약무엇을 누구를 위해 만드는가
② 절대 규칙어기면 실패인 것(오프라인·데이터 보호)
③ 진행 단계단계마다 완료 기준

주소사내 접근 제한 안에서링크를 아는 사람은 누구나 열 수 있고, 저장소도 공개(Public)로 안내하는 경우가 많습니다
AI에 주는 것열 이름 · 가상 값회사 숫자를 SQL에 채워 붙여넣게 합니다 → 안전망 위반
인터넷 의존오프라인에서도 열림외부 CDN·웹폰트를 불러와 사내망에서 막힐 수 있습니다
회사 숫자에는 쓰지 마세요링크가 새면 데이터도 샙니다. 외부 서비스에 올려도 되는 범위는 사내 지침이 정합니다(5쪽 안전망). 따라 해 보고 싶다면 가상 숫자로만 연습하세요. 무료 플랜은 업무(상업적) 사용이 약관상 제한될 수 있으니 확인이 필요합니다.
그래도 가져다 쓸 것
  • 하루에 하나: 가장 급한 하나를 끝까지 하면 두 번째부터 빨라집니다.

지금 상황할 것단계
AI가 만든 화면이 내 질문과 안 맞는다질문을 한 문장부터 다시 정하고, 화면 정의서를 새로 받는다. 처음이라면 질문 1~2개·화면 1장(MVP)부터STEP 1
원하는 배치를 말로 설명하기 어렵다칸에 번호를 붙인 스케치 한 장(또는 글로 쓴 배치)을 함께 준다STEP 2
화면이 지저분하다 · 만들 때마다 스타일이 다르다디자인 기준 7가지로 점검시키고 고칠 곳 3개만 지정. 디자인 값(토큰)을 표로 먼저 정해 그 값만 쓰게 한다STEP 3
"별로야"밖에 말이 안 나온다느낌→말 표로 바꾸고, 수정 틀로 3가지만 고친다STEP 4
AI가 지시서를 요약하며 규칙을 바꿨다"요약 금지, 문구·숫자 변경 금지"를 넣고 단계마다 보고받는다STEP 6
대화가 길어져 AI가 앞 내용을 잊는다PROGRESS.md를 읽히고 새 대화에서 이어간다STEP 6
엑셀 열 이름이 바뀌었다오류가 알려 주는 비슷한 이름을 동의어로 추가하게 한다STEP 6
화면이 비었거나 오류가 난다 · 코드가 끊겼다F12 Console의 빨간 글씨를 그대로 AI에게. 끊긴 코드는 "끊긴 곳부터 이어서"막혔을 때
숫자가 의심스럽거나 화면마다 다르다정답값 대조표 + 엑셀에서 3개 직접 계산, 모든 카드가 같은 목록에서 계산되는지 확인. 새 대화에서 한 번 더 검토STEP 7
마음에 든 버전으로 돌아가고 싶다저장 지점(폴더 복사 v1·v2…)으로 되돌린다안전망
데이터를 AI 대화창에 붙여넣었다즉시 멈추고 담당자에게 알린다안전망
엑셀·키를 저장소에 올렸다즉시 담당자에게 알린다. 지워도 이력에 남는다STEP 8
밖(집·휴대폰)·인터넷 주소로 열고 싶다주소를 그냥 열지 말고 로그인 제한부터. 클라우드 방식은 가상 숫자 연습용. 회사 데이터는 담당자와 상의응용

끝났는지 확인하기

공유하기 전에 아래를 모두 체크하세요. 하나라도 비어 있으면 해당 STEP으로 돌아갑니다.

  • 질문 2~3개·KPI가 한 장에 있고, 첫 버전(MVP)은 1~2개다 (STEP 1)
  • AI에게 데이터 내용을 붙여넣지 않았다 — 열 이름·가상 값만 (안전망)
  • 원하는 배치를 스케치 한 장(또는 글)으로 AI에게 줬다 (STEP 2)
  • 목업을 보며 3번 이상 고쳤다 (STEP 2~4)
  • 3초 테스트를 통과했다 — 처음 보는 사람이 핵심 숫자와 좋고 나쁨을 말한다 (STEP 3)
  • 규칙표(경계값 포함)와 임시 기준 목록이 있다 (STEP 5)
  • 지시서에 단계·완료 기준·하지 말 것이 있다 (STEP 6)
  • AI 코딩 도구가 단계마다 보고했고 PROGRESS.md가 있다 (STEP 6)
  • 정답값 대조표가 모두 일치하고, 직접 계산한 숫자 3개가 화면과 같다 (STEP 7)
  • 만든 AI와 별개로 새 대화에서 한 번 더 검토시켰다 (STEP 7)
  • 데이터 파일이 저장소에 없다 — .gitignore + 커밋 전 점검 (STEP 8)
  • 갱신 순서를 적어 뒀고, 배포 승인은 내가 한다 (STEP 8)
  • 필요한 곳에 "가상 샘플"·"임시 기준" 표시가 있다 (STEP 2·5)
