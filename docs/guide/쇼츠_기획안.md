# 교육용 쇼츠 기획안 v3 — "AI로 대시보드, 처음부터 다시 만들지 않기" (6편)

가이드(`index.html`, 23쪽)를 **45초 클립 6편**으로 만듭니다. 6편을 **각각 따로 만든 뒤 순서대로 이어 한 영상으로 합칩니다.** 한 편에 **한 가지 행동**만 남기고, 편마다 복사해 쓸 **프롬프트 한 줄**을 줍니다.

## 4. 합치기 방법

- **따로 촬영·편집**하고 마지막에 1 → 6 순서로 이어 붙입니다. 약 4분 30초라 쇼츠(60초 제한)가 아닌 **일반 영상**으로 올리고, 6편은 필요하면 쇼츠로도 따로 올릴 수 있습니다(그때는 연결 문장 4초를 잘라 냄).
- 편마다 맨 앞 **1초 번호 카드**("2/6 안전")를 같은 디자인으로 넣습니다.
- 첫 편 앞에만 전체 소개 한 줄("지금부터 여섯 가지만 알면 됩니다")을 더합니다.
- 편 끝 **연결 문장**이 다음 편 훅으로 이어지는지, 이어 붙여 소리 내어 확인합니다.
- **프롬프트 자막 화면은 같은 위치·스타일**로, 배경음·목소리 크기·자막 글꼴도 6편 동일하게.
- 관통 소재(5곳 표)는 같은 디자인으로 재사용합니다. 평균 77.5는 편 3에서 보여 주고, 편 5에서 검증하고, 편 6에서 마무리합니다.
- 설명란: **장 시간 표시**(0:00 시작 / 0:45 안전 …), 전체 프롬프트 모음, 출처 표기, 가이드 위치. 마지막 화면 고정 문구: "전체 가이드(23쪽)는 [사내 위치]에서" (위치를 채울 것).
- 촬영 순서: 편 1·2 → 3·4 → 5·6. 6편이 모두 끝난 뒤 한 번에 합쳐 점검합니다.

## 5. 공통 제작 규칙

1. **실제 업체명·점수·사내 화면은 절대 화면에 넣지 않습니다.** 5곳 가상 표와 가이드의 가상 샘플만 사용합니다.
2. 사내 도구 로그인 화면·주소·계정은 가려서 촬영합니다. F12 장면의 오류 글씨도 가상으로 만든 것만 씁니다.
3. 프롬프트는 화면에 큰 글씨 한 줄로 띄우고, 설명란에 전문을 넣어 복사하게 합니다.
4. 외부 영상·글의 화면과 그림은 가져다 쓰지 않습니다. 아이디어를 쓴 곳은 설명란에 출처 표기(혼잡스, 복리부자, Notion 공개 자료, unslop CC BY 4.0, DESIGN.md 게시물).
5. 도구의 기능·요금·버전은 바뀌므로 영상에서 특정 버전·요금을 말하지 않습니다. 편 4의 스타일 서비스는 이름을 열거하지 않고 "공개된 좋은 스타일"로만 말합니다.
6. 클라우드 방식(Supabase·Vercel)과 개인용 서버는 이 영상에서 다루지 않습니다. 필요하면 별도 영상으로 만들되 "회사 데이터에는 쓰지 않는다"를 먼저 말합니다.
7. 음원·효과음은 사용 허가된 것만, 자막은 맞춤법 점검 후 업로드합니다.
