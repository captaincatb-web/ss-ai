# 교육 자료 — 엑셀로 만드는 정적 대시보드

협력사 종합평가 대시보드를 사례로, 다른 사람이 **자기 엑셀로 자기 대시보드를 만들 수 있게** 알려 주는 실습형 교육 자료입니다. 관통 문장: **"무거운 일은 빌드에서 끝내고, 브라우저는 그림만 그린다."**

| 위치 | 내용 |
|---|---|
| `make/index.html` | 교육 슬라이드 63장 (1920×1080, 한 파일, 인터넷 불필요) |
| `make/대시보드_만들기_교육.pdf` | 같은 내용의 PDF (쪽마다 슬라이드 1장, 단계별 공개 항목은 모두 표시) |
| `starter/` | **실습 키트** — 가상 엑셀 → 빌드 → 대시보드 (`starter/README.md`의 6단계) |
| `src/` | 슬라이드 원본(묶음 `d01`~`d10`)과 조립 스크립트 `build.py` |
| `img/` | 슬라이드에 넣은 화면 캡처 (가상 샘플 데이터) |

## 슬라이드 구성 (9개 장)

| 장 | 제목 | 시간 | 핵심 |
|---|---|---|---|
| 1 | 준비 | 10분 | 도구 3가지, 설치 확인, 데이터 약속 4가지 |
| 2 | 원리와 작업 흐름 | 25분 | 서버 없는 구조, 5단계 로드맵, **AI와 함께 만드는 6단계**, 구현 지시서, 첫 요청문 |
| 3 | 설계 | 15분 | 질문 → KPI → 화면, 화면 3종, 화면 정의서 |
| 4 | 데이터 계약 | 25분 | 열·키·단위, 동의어 매핑, 실패 5가지, **1개년부터 시작** |
| 5 | 빌드 | 30분 | 읽기→정리→계산→내보내기, 점검 리포트, 정답값 |
| 6 | 화면 | 20분 | 상태 1개 + render 1회, 차트 고르는 기준, 드릴다운 |
| 7 | 설정·배포 | 15분 | 설정 파일, 정적 배포 3가지, 보안 규칙, **서버로 옮길 때** |
| 8 | 사례 해부 | 10분 | 완성 화면 읽기, 구조 해부, 가져갈 뼈대/바꿀 살 |
| 9 | 실습 | 90분 | 실습 6스텝, 체크리스트, FAQ, **확인 퀴즈**, 다음 단계 |

## 보는 법 (키보드)

`←` `→` `Space` 이동 · `Home` `End` 처음/끝 · `1`~`9` 장 이동 · `O` 전체 보기(개요) · `T` 다크 모드 · `F` 전체 화면. 주소의 `#slide=번호`로 특정 쪽을 바로 열 수 있습니다. 코드 블록 오른쪽 위 **복사** 버튼으로 명령을 그대로 복사할 수 있고, 마지막의 "오늘의 세 문장"과 퀴즈 정답은 키를 누를 때마다 하나씩 나타납니다.

## 채워 넣을 곳 (대괄호로 표시됨)

- 1.1 · `[사내 설치 안내 링크 · 담당자]` — 사내 표준 설치 방법
- 9.5 · `[담당자 · 문의 채널]`, `[실습 키트·교육 자료 위치]`
- 표지·장 표지의 소요 시간(총 4시간 = 설명 150분 + 실습 90분)은 교육 일정에 맞게 고치세요.

## 고치는 법

1. `src/d0X_*.html`의 해당 슬라이드를 고칩니다. 슬라이드는 `<section class="slide" data-chapter="…" data-title="…">` 한 덩어리입니다. 화면 캡처는 `{{img:이름}}`으로 넣습니다(`img/이름.jpg`).
2. `python src/build.py` — 한 파일(`make/index.html`)로 조립하고 슬라이드 수·제목·이미지를 점검합니다. 목차의 쪽수, 장 표지의 하위 목록, 개요는 제목(`data-title`)에서 자동으로 만들어집니다.
3. PDF: 브라우저에서 `make/index.html`을 열고 인쇄 → 대상 **PDF로 저장**, 여백 **없음**, **배경 그래픽** 켜기 (용지 크기는 1920×1080으로 자동 지정됩니다).

## 확인한 것

- 63장 모두 1920×1080 안에 들어오고(내용 아래 끝 ≤ 1000px, 잘림·넘침 0), 콘솔 오류 0, 외부 요청 0건
- 이동·단축키·개요·다크 모드·단계별 공개·복사·목차 링크·해시 열기·창 크기별 맞춤(1280×720, 1024×768, 390×844)
- 인쇄(PDF) 63쪽
- 실습 키트: 깨끗한 엑셀 → 경고 0건, `--dirty` → 경고 5건, 열 이름 변경 → 안내 오류 후 동의어 추가로 통과, 과거 연도 추가 → 추이 3/5 → 5/5

## 주의

- 화면 캡처는 가상 샘플 데이터이지만, **사내 엑셀의 열 이름에서 온 화면 라벨**(예: "D/T 종합 점수", "평가조직")이 보입니다. 사내 교육용으로 쓰고, 외부에 공유하기 전에는 확인하세요.
- 실습 키트의 `data/`·`dist/`는 `.gitignore`에 들어 있습니다. 실제 엑셀을 저장소에 올리지 마세요.
