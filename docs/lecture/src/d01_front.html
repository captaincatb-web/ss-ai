    1.1

    필요한 것은 세 가지입니다

    1

    Python 3.8 이상

    엑셀을 읽는 빌드 스크립트가 씁니다. 엑셀 읽기용 openpyxl 패키지가 함께 필요합니다.

    2

    브라우저

    Chrome 또는 Edge. 만든 화면을 여는 곳입니다. 서버도 인터넷도 필요 없습니다.

    3

    AI 코딩 도구

    사내 opencode. 코드를 쓰고 고칩니다. 사람은 정하고 검수합니다.

    작업 폴더는 이렇게 생깁니다

    my-dashboard/
├─ data/2026/      ← 엑셀을 넣는 곳 (저장소에 올리지 않음)
├─ build.py        ← 엑셀 → dist/
├─ settings.js     ← 기준·열 이름 설정
├─ src/index.html  ← 화면
└─ dist/           ← 결과 (이 폴더만 옮기면 됨)
    설치는 사내 표준 안내를 따르세요

    설치 확인 — 세 가지가 모두 되면 다음으로

    터미널(명령 프롬프트 · PowerShell)에서

python --version

    • 그래도 안 되면 사내 설치 안내 · 담당자
    1.3

    시작 전에 약속 4가지

    교육 내내, 그리고 실제 업무에서도 똑같이 지킵니다

    ① 연습은 가상 데이터로

    실제 데이터는 사내 PC 밖으로 나가지 않습니다. 오늘은 실습 키트의 가상 엑셀만 씁니다.

    ② 엑셀·data.js는 저장소에 올리지 않는다

    한 번 올린 파일은 지워도 이력에 남습니다. 사내 GitHub도 마찬가지입니다.

    ③ AI에게는 열 이름과 규칙만

    업체명·점수 같은 내용은 붙여 넣지 않습니다. 열 이름도 사내 용어이면 사내 AI 도구에만 알려 줍니다.

    ④ 외부 연결 없이 만든다

    CDN·웹폰트·외부 API를 쓰지 않습니다. 인터넷이 끊겨도 열려야 합니다.
