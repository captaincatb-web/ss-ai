설계
5단계 로드맵의 1단계 —
질문에서 출발해 화면까지 정합니다
약 15분
    3.1

    질문 없는 차트는 넣지 않습니다

    질문 → KPI(숫자) → 화면 순서로 정합니다

    질문
    KPI — 숫자 + 비교 기준
    화면
    올해 결과는 지난해보다 좋아졌나?
    →
    평균 점수 + 전년 대비등급별 비율
    →
    결과 요약맨 위 핵심 숫자 + 결론 3줄
    어느 영역·항목이 약한가?
    →
    영역별 평균 · 70점 미만 비율전년 대비 증감
    →
    항목별 결과영역 → 평가항목 → 하위 협력사
    이 협력사는 무엇을 개선해야 하나?
    →
    점수·등급 이동 · 항목 순위5개년 추이
    →
    협력사별 결과목록 → 개별 상세
    KPI는 "숫자 + 비교 기준"으로 정의합니다
    전년·목표·평균 같은 비교 기준이 없는 숫자는 좋은지 나쁜지 알 수 없습니다.
    3.2

    화면은 세 가지 패턴이면 충분합니다

    경영진

    ① 요약

    1분 안에 상황 파악

    • 결론 3줄
    • 핵심 숫자 4개 (+전년)
    • 5개년 추이
    • 부진·우수 명단 링크
    담당자

    ② 분석

    어디가 문제인지 찾기

    • 영역 → 항목 → 하위 목록
    • 필터(연도·조직·업종…)
    • 기준선(목표·평균)
    • 표 보기 · CSV
    리뷰

    ③ 개별

    한 대상을 깊게 보기

    • 목록(검색·칩·정렬)
    • 5개년 추이 + 등급 이동
    • 항목별 점수와 순위
    • 세부 항목 근거
    핵심만 ↔ 상세 보기
    모든 화면은 기본이 "핵심만"입니다. 상단의 상세 보기를 켜면 세부 카드·표가 펼쳐집니다. 화면을 늘리기 전에 기존 3종으로 풀 수 없는지 먼저 봅니다.
    3.3

    화면 정의서 한 장 — AI에게 줄 첫 자료

    화면마다 이 표 하나를 채웁니다 (예: 결과 요약)

    항목내용 (예)
    질문올해 평가 결과는 지난해보다 좋아졌는가?
    KPI 정의평균 종합 점수(전년 대비 · 목표까지) · A등급 비율 · C·D 비율 · 부진사/우수사 후보 수
    차트·표5개년 추이(선) · 등급 구성(분할 막대) · 영역별 전년·올해(표) · 변화가 큰 업종·협력사
    필터평가 연도 · 조직 · 권역 · 업종 · 등급 (여러 개는 AND)
    클릭하면명단 링크 → 협력사별 결과로 이동 · 업종 타일 → 필터 켜기/끄기
    데이터 출처평가결과표(점수·등급·전년) · 영역점수표
    완료 기준필터를 바꿔도 모든 카드가 같은 협력사 목록에서 다시 계산된다
    3.4

    AI에게 이렇게 — 가상 데이터로 목업부터

    요청문 예

    아래 화면 정의서대로 HTML 목업을 만들어줘.

- 실제 값은 모른다. 열 이름만 알려 주니 값은 가상으로 만들어
  (협력사 코드, 협력사명, 업종, 종합 점수, 등급,
   전년 종합 점수, 영역별 점수 5개)
- 단일 HTML, 외부 CDN·웹폰트 없이, 라이트/다크 모드
- 핵심 숫자를 맨 위에, 색은 의미 있을 때만
  (파랑=좋음, 빨강=나쁨, 회색=보통)
- 차트마다 "그래서?" 한 줄 해석
