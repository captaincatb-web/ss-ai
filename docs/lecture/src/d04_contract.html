    4.3

    폴더 규칙 — 1개년부터 시작합니다

    연도는 폴더 이름, 파일 이름은 상관없음

    data/
├─ 2026/  ← 기준연도: ①②③④ 모두
├─ 2025/  ← 과거 연도: ① 만 있어도 됨
├─ 2024/
└─ …
    • 종류는 헤더(열 이름)로 판별
    • 기준연도 = 4종이 모두 있는 가장 큰 연도
    • 격년으로 줘도 됨 (“전년 점수” 열로 보충)

    넣은 파일 → 화면에서 되는 것

    넣은 것되는 것
    기준연도 4종만모든 화면 + 전년 비교 (추이는 2점)
    + 과거 연도 ①점수·등급 추이의 점이 늘어남
    + 과거 연도 ②영역별 추이까지 채워짐
    과거 연도 ③④필요 없음 (읽지 않음)
    5년치를 한꺼번에 준비하지 마세요
    1개년으로 끝까지 돌려 본 뒤, 과거 연도를 최근 것부터 하나씩 추가합니다. 열 이름 매핑 같은 위험은 첫 연도에서 모두 드러납니다.

    엑셀이 실패하는 원인은 대부분 다섯 가지

    #증상원인빌드가 하는 일
    1병합 셀병합 범위의 첫 칸에만 값이 있고 나머지는 빈 칸오른쪽으로 채워서 그룹 이름을 만든다

    4빈칸 = 0평균이 왜곡됨빈칸은 "없음"으로 두고 평균에서 제외
    5연도별 열 이름 변경양식이 해마다 조금씩 바뀜동의어 매핑, 안 되면 중단하고 안내

    4.6

    AI에게 이렇게 — 열 이름만 알려 주기

    요청문 예

    파일 ①의 열 이름은 아래와 같다. (값은 줄 수 없다)
  협력사 코드 | 협력사명 | 업종 | 종합 점수 | 등급
  | 전년 종합 점수 | 전년 등급

- 제목 줄·빈 줄이 위에 있고 헤더는 3행째일 수 있다
- 병합된 그룹 헤더가 있을 수 있다
- 열 이름은 해마다 띄어쓰기 등이 조금 바뀐다

이 가정으로 읽기 규칙을 제안하고,
가정을 "가정 목록" 표로 적어줘.

    받으면 확인할 것

    • AI가 한 가정이 목록에 적혔나?
    • 값(업체명·점수)을 붙여 넣지 않았나?
    • 동의어·헤더 행 규칙이 있나?
    열 이름도 사내 용어일 수 있습니다
    외부 AI에는 '평가점수'처럼 일반화한 이름으로, 실제 이름은 사내 AI 도구에만 알려 줍니다.
