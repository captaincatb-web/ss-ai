    8.1

    빠른 투어 ① — 화면 위쪽은 모두 같습니다

    1메뉴 — 화면 3개를 오갑니다
    2필터 줄 — 모든 화면에 적용. 고르면 "적용 중 필터" 칩
    3상세 보기 · 다크 모드 — 핵심만 ↔ 상세
    4결론 3줄 — 가장 먼저 읽는 문장
    5핵심 숫자 — 점수 + 전년 대비 + 추이
    6AI 손잡이 — 오른쪽 대화 패널을 엽니다

    ※ 가상 샘플 데이터 화면입니다 (협력사 1,248개 · 임의 생성)

    8.2

    빠른 투어 ② — 결과 요약은 위에서 아래로

    1
    결론 3줄

    평균·등급 구성·가장 약한 영역

    2
    핵심 숫자 4개

    평균 · A 비율 · C·D 비율 · 명단 수 (+전년)

    3
    등급 결과

    등급별 협력사 수와 비율, 올해 vs 전년

    4
    5개년 추이

    평균 점수 · 등급 구성의 흐름

    5
    항목별 점수 증감

    영역 → 평가항목으로 펼치며 확인

    6
    변화가 큰 곳 · 명단

    업종·협력사 TOP, 부진사·우수사 후보

    읽는 요령
    위에서 결론 → 숫자 → 근거 순서로 내려갑니다. 모든 카드는 같은 필터를 따릅니다.
    8.3

    숫자를 읽는 규칙 — 오해 방지

    이렇게 읽지 마세요이렇게 읽으세요
    평균이 올랐으니 전체가 좋아졌다평균과 함께 C·D 비율(80점 미만)을 봅니다
    전년 대비는 모든 협력사 기준이다전년 평가가 있는 협력사만 비교합니다 (신규는 제외)
    추이선은 그해 평가된 모든 협력사다기준연도 평가 협력사 집단을 과거까지 따라간 값입니다
    부진사·우수사 명단은 확정이다"임시 기준" 배지가 있으면 기준이 아직 확정 전입니다
    영역 점수가 낮다 = 그 영역 협력사가 나쁘다영역 점수는 배점 대비 환산(0~100) 평균. 기준선(평균·70점)과 함께 봅니다
    등급 기준

    A 90점 이상 · B 80점 이상 · C 60점 이상 · D 60점 미만

    색

    파랑 = 좋음 · 빨강 = 나쁨 · 회색 = 보통 (▲▼ 병행)

    출처 i

    카드 제목 옆 i에 마우스 → 쓰는 엑셀 열 이름

    8.4

    구조 해부 — 화면의 각 부분은 어떤 코드인가

    1필터 줄 = state.filters
    2영역 타일 = 선택 상태 + atile()
    3카드 = card() 제목·i·표 보기
    4선 차트 = SVG 문자열 lineYears()
    5막대 목록 = hbars()
    6표 = simpleTable()
    7CSV = downloadCSV() (BOM)
    이 모두가 같은 L에서
    필터를 바꾸면 전부 다시 그려집니다.
    8.5

    AI 대화 패널 — 연결 자리만 두는 설계

    1손잡이 — 누르면 패널이 열림
    2"API 미연결" — 연결 전엔 데모 답변
    3현재 화면 포함 — 화면 정보만 함께 전달
    4추천 질문 — 화면마다 달라짐
    window.SUPPLIER_CHAT = {
  name: '사내 AI',
  ask: async (req) => '답변'
};  // req = { message, history, context }
    호출 코드는 넣지 않는다
    주소·키는 코드에 없고, ask 한 곳만 비워 둡니다.
    8.6

    가져갈 뼈대, 바꿀 살

    내 대시보드에서는 무엇을 그대로 쓰고, 무엇을 바꾸나

    뼈대 — 그대로 가져갑니다

    • 빌드 4단계 + 점검 리포트
    • 상태 1개 + render() 1회
    • 카드 · 차트 · 표 부품
    • 설정 파일로 기준 분리
    • 정적 배포 + 보안 규칙
    • AI 협업 6단계 + 지시서 구조

    살 — 내 업무에 맞게 바꿉니다

    • 질문과 KPI
    • 열 이름 · 스키마 · 키
    • 등급 구간 · 기준 · 라벨
    • 화면 구성 (3종 패턴 안에서)
    • 색 · 로고 · 문구
    • 배포 위치 · 갱신 주기
    시작은 가장 작게
    화면 1개, KPI 4개, 엑셀 1개, 연도 1개로 끝까지 돌려 본 뒤 늘립니다. 실습 키트가 정확히 그 크기입니다.
