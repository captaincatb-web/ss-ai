    실습 6스텝 — 실습 키트(starter/)

    #할 일명령 · 동작이렇게 나오면 성공
    1가상 엑셀 만들기python make_sample.pydata/2026/에 엑셀 2개
    2빌드python build.py경고 0건 · 평균 80.8 · A 30 / B 77 / C 92 / D 1
    3열기dist/index.html 더블클릭KPI 4 + 차트 3 + 표 · 추이 자료 2/5개년
    4점검 연습python make_sample.py --dirty → 빌드경고 5건 → 리포트에서 5가지를 찾아 설명
    5열 이름 바꿔 보기엑셀의 '종합 점수'를 '총점수'로 → 빌드 → 오류 → settings.js에 동의어 추가 → 빌드오류 안내를 읽고 스스로 고쳐서 통과
    6과거 연도 채우기python make_sample.py --add-year 2025 → 빌드 (2024·2023·2022도)배지 3/5 → 5/5, 배지가 사라짐
    4번을 하고 나면 data/가 "문제 있는" 파일로 바뀝니다
    data/ 폴더를 지우고 1번부터 다시 하면 되돌아갑니다. 파이썬 버전이 다르면 정답값이 조금 다를 수 있으니, 그때는 첫 실행 결과를 기준으로 삼으세요.

    완성 화면과 체크리스트

    • 설치 3체크 통과 (1.2)
    • 빌드 경고 0건, 정답값 일치
    • index.html 더블클릭으로 열리고 필터·검색·정렬 동작
    • 추이 카드에 "자료 2/5개년" 배지
    • 점검 연습: 경고 5건의 원인을 설명할 수 있다
    • 열 이름을 바꾼 뒤 settings.js에 동의어를 추가해 통과
    • 과거 연도를 추가하면 배지가 올라가고 5/5에서 사라진다
    • dist/를 다른 폴더로 복사해도 열린다
    • data.js 이름을 바꿔 열면 오류 화면 (샘플로 대체 안 됨)
    • .gitignore에 data/ dist/ 포함

    자주 막히는 곳 — 함정과 FAQ

    빌드는 성공했는데 숫자가 이상해요점검 리포트부터: 경고 · 행 수 · 정답값 순서로 확인
    더블클릭했는데 빈 화면이에요오류 화면의 안내대로 data.js가 index.html과 같은 폴더인지, 빌드했는지 확인
    한글이 깨져요저장은 UTF-8(BOM 없음). PowerShell 5.1의 Set-Content -Encoding UTF8은 BOM을 붙입니다
    엑셀을 열어 둔 채 빌드했어요~$ 임시 파일은 건너뜁니다. 저장하고 닫은 뒤 다시, 안 되면 복사본으로
    열 이름이 바뀌었어요오류가 알려 주는 비슷한 이름을 settings.js columns에 동의어로 추가
    과거 연도를 넣었는데 영역 추이가 비어요과거 연도 ①만 있으면 점수·등급 추이만 채워집니다. 영역 추이는 ②도 필요
    서버에 올렸더니 빈 화면이에요상대 경로 · .js UTF-8 · 캐시 · data.js를 올렸는지 · 접근 권한
    엑셀을 저장소에 올려 버렸어요즉시 담당자에게 알리세요. 지워도 이력에 남으므로 이력 삭제는 담당자가 합니다
    9.4

    확인 퀴즈 — 6문항

    먼저 답을 말해 본 뒤, 키를 눌러 정답을 하나씩 확인합니다

    ① 90.0점은 몇 등급? 89.9점은?A, B — 경계값은 테스트로 고정합니다
    ② 점수 칸이 비어 있으면 평균은?0으로 세지 않고 제외 (빈칸 = 없음)
    ③ 경고가 1건 나왔다. 배포해도 될까?아니요 — 원인을 확인하기 전에는 배포하지 않는다
    ④ 과거 연도를 넣었는데 영역 추이가 비어 있다그 해의 ②(영역점수) 파일이 필요하다
    ⑤ data.js를 못 읽으면 화면은?원인을 알려 주는 오류 화면 (샘플로 대신 보여 주지 않는다)
    ⑥ AI에게 줘도 되는 것은?열 이름·규칙(사내 도구) — 업체명·점수 같은 내용은 안 됨
