# 실습 키트 — 엑셀 → 빌드 1줄 → 대시보드

가상 엑셀(협력사 200개)을 만들고, 빌드해서, 브라우저로 여는 **가장 작은 완성품**입니다. 이 키트를 먼저 돌려 본 뒤 내 엑셀로 바꿔 가면 됩니다.

필요한 것: **Python 3.8+**, `openpyxl` (`pip install openpyxl`), 브라우저. 서버·인터넷은 필요 없습니다.

## 폴더

```
starter/
├─ make_sample.py   가상 엑셀 만들기 (실습용)
├─ build.py         엑셀 → dist/  (읽기 → 정리 → 계산 → 내보내기)
├─ settings.js      기준·라벨·엑셀 열 이름(동의어) — 바뀔 값은 여기서
├─ src/index.html   화면 (바닐라 JS + SVG, 외부 라이브러리 없음)
├─ data/            엑셀을 넣는 곳 (연도별 폴더) — 저장소에 올리지 않음
└─ dist/            빌드 결과 — 이 폴더만 옮기면 어디서나 열림
```

## 6단계

| # | 할 일 | 명령 / 동작 | 이렇게 나오면 성공 |
|---|---|---|---|
| 1 | 가상 엑셀 만들기 | `python make_sample.py` | `data/2026/평가결과.xlsx`, `영역점수.xlsx` 생성 |
| 2 | 빌드 | `python build.py` | `[점검] 경고 0건` · `평균 80.8점 · A 30 / B 77 / C 92 / D 1` (정답값) |
| 3 | 열기 | `dist/index.html` 더블클릭 | KPI 4개 + 차트 3개 + 표, 추이 카드에 **자료 2/5개년** |
| 4 | 점검 연습 | `python make_sample.py --dirty` → `python build.py` | `경고 5건` — `dist/data_check.txt`에서 5가지를 찾아 설명 |
| 5 | 열 이름 바꿔 보기 | 엑셀의 `종합 점수`를 `총점수`로 고침 → 빌드 → 오류 확인 → `settings.js`의 `columns.score`에 `"총점수"` 추가 → 빌드 | 오류 없이 빌드됨 |
| 6 | 과거 연도 채우기 | `python make_sample.py --add-year 2025` → 빌드 → (2024, 2023, 2022도) | 추이 카드가 3/5 → 5/5개년으로 늘고 배지가 사라짐 |

4단계를 하고 나면 `data/`가 문제가 섞인 파일로 바뀝니다. 되돌리려면 `data/` 폴더를 지우고 1단계부터 다시 하세요.
정답값(평균 80.8점 등)은 가상 엑셀을 같은 방법으로 만들 때의 값입니다. 파이썬 버전이 다르면 조금 다를 수 있으니, 그때는 첫 실행 결과를 기준으로 삼으세요.

## 내 엑셀로 바꾸기

1. 엑셀을 `data/<연도>/`에 넣습니다. 파일 이름은 상관없습니다(열 이름으로 종류를 판별).
2. 빌드합니다: `python build.py --data-dir <엑셀 폴더> --out dist` (경로를 코드에 적지 않습니다).
3. `필수 열 … 을(를) 찾지 못했습니다` 오류가 나면 안내된 비슷한 이름을 `settings.js`의 `columns`에 동의어로 추가합니다.
4. `dist/data_check.txt`의 경고를 모두 읽고, **경고 0건이 아니면 배포하지 않습니다.**
5. 처음에는 **기준연도 1개년만** 넣어도 됩니다. 과거 연도는 `평가결과` 하나만 있어도 추이 점이 늘어납니다.

## 지켜야 할 것

- 실제 엑셀과 `dist/data.js`를 저장소(GitHub)에 올리지 않습니다 (`.gitignore`에 포함).
- 엑셀 내용(업체명·점수)을 AI 대화창에 붙여 넣지 않습니다. 열 이름과 규칙만 알려 줍니다.
- `settings.js`는 JSON 호환 형식입니다: 키와 문자열은 큰따옴표, 마지막 항목 뒤 쉼표 금지, 주석은 줄 맨 앞 `//`만.
