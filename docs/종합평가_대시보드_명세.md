# 협력사 종합평가 대시보드 — 구현 명세 (opencode 전달용)

## 0. 목적
협력사 종합평가 결과를 4개 엑셀 원장으로부터 읽어, 요약 → 협력사 → 영역 → 평가항목 → 세부항목 순으로 드릴다운하는 대시보드를 만든다.
실제 데이터는 사내 정보이므로 **코드에 포함하지 않는다.** 엑셀 업로드(또는 사내 지정 경로) 방식으로 로드하고, 개발·테스트는 가상 샘플 데이터 생성기로 한다.

## 1. 데이터 소스 (엑셀 4종)
헤더는 2단(그룹행 + 컬럼행)이며, 그룹행은 병합 셀이다. 파싱 시 그룹행을 컬럼명 접두사로 합치거나(예: `평가결과.배점`, `전년도 결과.배점`) 위치로 구분한다. 1번 파일은 "배점/일반항목 평점/…" 컬럼이 당해·전년도에 중복되므로 반드시 그룹으로 구분한다.

| 파일 | 이름(가칭) | 행 단위 | 핵심 컬럼 |
|---|---|---|---|
| 1 | 평가결과 요약 | 협력사 × 세부평가단위 | D/T 코드, 협력사 코드/명, 협력사 확인, 평가조직, 권역 코드/명, 내/외자, 평가단위, 세부 평가단위 코드/명, 세부업종그룹 / (당해) 배점, 일반항목 평점, 일반항목 환산점수, 가산점, 평가 점수, 점수 변동, D/T 종합 점수, D/T 최종 등급 / (전년도) 배점, 일반항목 평점, 일반항목 환산점수, 가산점, 평가 점수, D/T 종합 점수, D/T 최종 등급 |
| 2 | G/T 상세 | 협력사 × 평가조직 | 일반 조직, 평가조직, G/T 코드, D/T 코드, 협력사 코드/명, 권역, 국가, 내/외자, 업종, 세부 평가단위, 주거래, 대표코드, 기업 규모, 금형, 거래중단예정일, 거래중단일, 배점, 일반항목 평점/환산점수, 가산점, 평가 점수, 평가조직 등급, D/T 종합 점수, D/T 등급 반영비중-거래비중, D/T 거래비중별 개별합계/총합계, D/T 조정 전 등급, 등급 조정 대상, D/T 최종 등급, D/T 전년도 등급, G/T 종합 점수, G/T 등급, 영역 T·Q·R·D·C·E·F·A 각각 (배점, 평점, 환산점수, 배점(비중), 평점(비중)), G/T 등급 반영비중-거래비중 |
| 3 | 평가항목 상세 | 협력사 × 평가조직 × 세부평가단위 × 평가항목 | D/T 코드, 협력사 코드/명, 평가조직, 평가단위, 세부 평가단위 코드/명, 분류체계 유형, 분류체계, 평가항목 코드/명, 배점, 평점, 환산평점, 환산평점 변동, 이전 환산평점, 미적용 여부, 무실적 여부 |
| 4 | 세부항목 상세 | 평가항목 × 세부항목 | D/T 코드, 협력사 코드/명, 평가조직, 평가단위, 세부 평가단위 코드/명, 평가항목 코드/명, 세부 등록 주체, 배점, 평점, 환산 평점, 세부항목 코드/명, 세부항목 값 |

### 1.1 조인 키 (가정, 사내 확인 필요)
- 1 ↔ 2: `D/T 코드 + 협력사 코드 (+ 평가조직 + 세부 평가단위 코드)`
- 2/1 ↔ 3: `D/T 코드 + 협력사 코드 + 평가조직 + 세부 평가단위 코드`
- 3 ↔ 4: 위 키 + `평가항목 코드`
- 조인 키는 설정 파일로 분리해 사내에서 쉽게 수정할 수 있게 한다.

### 1.2 계층 및 등급 흐름
`평가항목 → (영역 T/Q/R/D/C/E/F/A) → 평가조직 등급 → (거래비중 가중) D/T 종합 점수 → 조정 전 등급 → 등급 조정 → D/T 최종 등급 → G/T 종합 점수/등급`

## 2. 데이터 처리 규칙
- 숫자 컬럼은 문자열·공백·`-`를 NaN으로 안전 변환한다.
- `미적용 여부`, `무실적 여부` = Y인 항목은 득점률·평균 계산에서 제외하고 별도 건수로 집계한다.
- 등급 순서는 설정으로 둔다(예: S>A>B>C>D). 등급 상승/하락은 이 순서로 판정한다. 등급 체계와 구간은 사내 값으로 교체 가능해야 한다.
- 득점률 = 환산점수 / 배점(0 나눗셈 방어).
- 전년 대비 = 당해 − 전년도(점수), 등급 순서 비교(등급).
- 거래중단 예정/중단 협력사는 플래그로 표시한다.
- 데이터 로드는 서버 메모리에서만 처리하고 외부로 전송하지 않는다.

## 3. 화면 구성

### 3.1 공통 필터 (전 화면 연동)
평가조직, 권역, 내/외자, 평가단위, 세부 평가단위, 세부업종그룹, 업종, 기업 규모, 주거래, 금형, 등급, 거래중단 여부, 협력사명 검색.

### 3.2 ① 종합 현황
- KPI 카드: 평가 대상 협력사 수, 평균 평가 점수, 전년 대비 평균 변동, 등급 상승/하락 협력사 수, 등급 조정 대상 수, 거래중단 예정 수
- 최종 등급 분포(막대) + 전년 대비 분포 비교
- 권역별·평가조직별 평균 점수
- 점수 분포 히스토그램

### 3.3 ② 전년 대비 변동
- 점수 변동 상위/하위 N개 협력사
- 등급 이동 매트릭스(전년 등급 × 당해 등급 히트맵)
- 상승/하락 협력사 목록

### 3.4 ③ 협력사 상세
- 헤더: 협력사 정보(코드, 권역, 국가, 업종, 규모, 거래중단 여부)와 D/T·G/T 등급 및 점수
- 영역 레이더 차트(T/Q/R/D/C/E/F/A, 득점률)와 평가조직별 비교 오버레이
- 평가조직별 등급 표와 거래비중, 조정 전/후 등급
- 평가항목 테이블(득점률, 환산평점 변동, 미적용/무실적 표시)
- 항목 클릭 시 세부항목 패널(4번 데이터) 표시

### 3.5 ④ 영역/항목 분석
- 영역별 평균 득점률 비교(전체 및 필터 기준)
- 평가항목별 평균 득점률 하위 N개(공통 취약 항목)
- 환산평점 변동이 큰 항목 TOP/BOTTOM
- 미적용/무실적 항목 현황

### 3.6 ⑤ 등급 조정/주의 목록
- 등급 조정 대상 목록(조정 전 → 조정 후)
- 거래중단 예정 협력사
- 주의 협력사(저등급 + 하락 + 점수 하위)

모든 표는 정렬, 검색, 엑셀 내보내기를 지원한다.

## 4. 비기능
- 한국어 UI, 숫자 천단위/소수점 1~2자리 통일
- 대용량(수만~수십만 행) 대비: 집계는 사전 계산, 표는 가상 스크롤/페이지네이션
- 컬럼명·등급 체계·조인 키·영역 매핑은 `config`로 분리(사내 환경 맞춤)
- 가상 샘플 데이터 생성 스크립트 포함(4개 파일 동일 구조)
- 스택은 사내 opencode 환경에 맞춰 선택

## 5. 사내 확인 필요 사항 (기본값으로 구현 후 config로 조정)
1. 협력사 확인, D/T, G/T의 의미와 계층(G/T ⊃ D/T 가정)
2. 등급 체계(S/A/B/C…)와 구간 기준
3. 분류체계 값과 영역 T/Q/R/D/C/E/F/A의 대응 및 약어 풀이
4. 1~4번 파일 간 정확한 조인 키
5. 평가 주기(월/분기/연)와 다중 기간 파일 지원 여부

## 6. 화면 목업
- 파일: `docs/종합평가_대시보드_목업.html` (단일 HTML, 외부 라이브러리 없음, 가상 샘플 데이터)
- 화면: 전체 결과 / 분야별 결과 / 협력사별 결과 (좌측 메뉴), 공통 필터 1줄
- 엑셀 컬럼 ↔ 화면 필드 매핑: 목업 스크립트의 `COLUMNS` 상수, 등급 구간·영역 배점·코드 목록: `CONFIG` 상수
- 각 카드 하단 "사용 항목"에 해당 카드가 쓰는 엑셀 컬럼명을 표기
- 목업에서 둔 해석(사내 확인 후 수정)
  - 배점 = 적용 항목 배점 합(미적용·무실적 제외), 평점 = 득점 합, 환산점수 = 평점 ÷ 배점 × 100
  - 평가 점수 = 일반항목 환산점수 + 가산점, D/T 종합 점수 = Σ(평가조직별 평가 점수 × 거래비중)
  - 3번 파일 분류체계 = 영역 코드(T~A), 분류체계 유형 = 정량/정성
  - KPI 추이선의 과거 3개년 값은 샘플 — 연도별 원장이 쌓일 때만 표시(현재 원장은 당해·전년도 2개년)
